# Memory-workshop

Консольная викторина по теме владения памятью в C++ (копирование, перемещение, операторы).

## Сборка

    clang++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o quiz

## Запуск

    ./quiz

## Ввод

- Меню: `0`, `1`, `2`.
- Вопрос: `1`, `2`, `3`.
- Допускаются пробелы и табуляции вокруг одной цифры: `" 2 "` принимается.
- Недопустимы: пустая строка, `1abc`, `1.0`, `+1`, `1 2`, числа вне диапазона — запрос повторяется без изменения счёта.
- После пояснения нажмите Enter (пустая строка или только пробелы) для продолжения.
- EOF (Ctrl+D) завершает программу; незавершённая игра помечается как прерванная.

## Структура

- `main.cpp` — единственный исходник (C++17, только стандартная библиотека).
- `checks.txt` — результаты проверок из таблицы приёмки.
